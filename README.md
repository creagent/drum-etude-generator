# Ритмика — генератор этюдов

Приложение: https://creagent.github.io/drum-etude-generator/

Откройте `index.html` в браузере. Один самостоятельный файл: HTML, CSS, JavaScript и SVG, без внешних библиотек, шрифтов и платных сервисов.

## Использование

Задайте количество тактов (1–64). Отдельными галочками выберите ноты и паузы: половинные, четвертные, восьмые, восьмые триоли и шестнадцатые. Нажмите «Сгенерировать этюд».

- Размер всегда 4/4; каждый такт содержит ровно четыре четверти.
- Генератор использует только отмеченные ноты и паузы. При нескольких выбранных длительностях каждый такт сочетает хотя бы две разные. Все пять длительностей не обязаны встретиться в одном такте.
- Триоли появляются полными группами по три на одну четвертную долю; если выбраны триольные ноты и паузы, они могут смешиваться внутри группы.
- Если для длительности отмечены и ноты, и паузы, вероятность паузы при её появлении — 30%. Можно выбрать только ноты или только паузы.
- Длительности считаются целочисленно (12 единиц на четверть, 48 на такт), без ошибок округления. Каждый шаг проверяется на возможность заполнить остаток такта.
- Ноты рисуются без стана и счёта долей. Половинные ноты имеют пустую головку; короткие ноты внутри доли соединяются рёбрами, у отдельных шестнадцатых в смешанной группе есть дополнительные короткие рёбра.
- Такты идут в общей строке с тактовыми чертами: четыре, если хватает места, иначе два. Неполная последняя строка допустима. На маленьком экране вся строка масштабируется по ширине, без горизонтальной прокрутки.
- Печать / PDF и экспорт SVG сохраняют общие строки тактов. Воспроизведение, лиги, точки и акценты не предусмотрены.

## Проверка

`node tests/generator.test.cjs` проверяет все 1023 непустых комбинации галочек, точную длину тактов, допустимые длительности, группы триолей, смешение длительностей, ошибки ввода и раскладку по строкам.

## Публикация

GitHub Pages публикует корень ветки `main`. Сборка и сторонние зависимости не требуются. После отправки изменений в `main` GitHub автоматически обновляет сайт.

Для работы без интернета сохраните `index.html` и откройте его в браузере. Установка в качестве PWA и офлайн-кэш сайта не включены.
