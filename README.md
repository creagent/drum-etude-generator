# Ритмика — генератор этюдов

Приложение: https://creagent.github.io/drum-etude-generator/

Откройте `index.html` в браузере. Это один самостоятельный файл: HTML, CSS, JavaScript и SVG. Установка, сервер, доступ к интернету и платные сервисы не нужны.

Настройте количество тактов (1–64), число равных позиций в четвертной доле (2–16), размер (2/4, 3/4 или 4/4) и вероятность паузы. Кнопка «Сгенерировать этюд» создаёт новый случайный рисунок.

В каждой позиции — удар или пауза одной и той же длительности. Длинные ноты, объединение пауз, лиги, акценты и воспроизведение в эту первую версию не входят. Полностью пустая доля или такт возможны: вероятность применяется независимо к каждой позиции.

Ноты рисуются в SVG без нотного стана и внешних шрифтов. Соседние ноты внутри доли соединяются рёбрами; одиночные получают флажки. Особые деления помечены отношением: 3:2 для восьмых триолей, 5:4 для шестнадцатых квинтолей и т. д. Для 6 и 7 используется отношение к четырём шестнадцатым; для 9–15 — к восьми тридцать вторым. Это упрощённая ритмическая запись с равномерной сеткой; все ноты и паузы сохраняют своё место.

На узком экране длинные такты прокручиваются по горизонтали. Можно отключить подсказки счёта, распечатать этюд, сохранить PDF через окно печати браузера или скачать SVG.

## Публикация

GitHub Pages публикует корень ветки `main`. Сборка и сторонние зависимости не требуются. После отправки изменений в `main` GitHub автоматически обновляет сайт.

Для работы без интернета сохраните `index.html` и откройте его в браузере. Установка в качестве PWA и офлайн-кэш сайта в эту версию не включены.
