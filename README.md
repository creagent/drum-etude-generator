# Ритмика — генератор этюдов

Приложение: https://creagent.github.io/drum-etude-generator/

Откройте `index.html` в браузере. Один самостоятельный файл: HTML, CSS, JavaScript и SVG, без внешних библиотек, шрифтов и платных сервисов.

## Использование

Задайте количество тактов (1–64). Отдельными галочками выберите ноты и паузы: восьмые, триоли, шестнадцатые, квинтоли и секстоли. Общим ползунком задайте количество пауз от 0 до 99% (по умолчанию 30%, шаг 5%, после 95% — 99%). Нажмите «Сгенерировать этюд».

- Размер всегда 4/4; каждый такт содержит ровно четыре четверти.
- Галочки задают только исходные длительности. Половинные и четвертные появляются исключительно при упрощении. У восьмых есть отдельная галочка «С точкой» (по умолчанию выключена), разрешающая восьмые с точкой при генерации и объединении. У остальных длительностей точек нет. При выключенной галочке точек нет во всём этюде.
- Каждая триоль, квинтоль или секстоль занимает одну четвертную долю. Ноты и паузы включены по умолчанию для всех пяти длительностей. Внутри группы каждая позиция независимо становится нотой или паузой согласно общему ползунку; группа не принуждается состоять из одних нот. Полностью звучащая группа может появиться случайно или при отключённых паузах. Над группой стоит скобка с числом 3, 5 или 6; у квинтолей и секстолей — шестнадцатые знаки (два ребра или флажка).
- Ползунок задаёт общую вероятность паузы для всех разрешённых длительностей и позиций внутри триолей, квинтолей и секстолей. Он также влияет на частоту выбора длительностей, для которых разрешены только ноты или только паузы. При 0% пауз нет; для генерации нужна хотя бы одна выбранная длительность ноты. Галочки ограничивают доступные варианты, поэтому при выборе одних нот пауз не будет, а при выборе одних пауз и значении выше 0% будут только паузы. Процент приблизительный: заполнение целого такта, сочетание длительностей и упрощение записи могут изменить итоговую долю пауз.
- Длительности считаются целочисленно (120 единиц на четверть, 480 на такт; 90 на восьмую с точкой, 40 на триольную позицию, 24 на квинтольную и 20 на секстольную), без ошибок округления. Каждый шаг проверяется на возможность заполнить остаток такта.
- Ноты рисуются без стана и счёта долей. Половинные ноты имеют пустую головку; короткие ноты внутри доли соединяются рёбрами, у отдельных шестнадцатых в смешанной группе есть дополнительные короткие рёбра.
- На мобильном экране (ширина до 700 px) в строке один такт, чтобы ноты были крупнее. На широком экране — четыре такта, если хватает места, иначе два. Неполная последняя строка допустима. Строка масштабируется по ширине без горизонтальной прокрутки; раскладка автоматически меняется при изменении размера экрана.
- «Скачать PDF» сразу сохраняет файл A4 без диалога печати. Длинные этюды автоматически делятся на страницы; строки и такты не разрываются. PDF создаётся локально из изображения нот в разрешении 300 dpi, без библиотек и сети. Экспорт SVG сохраняет векторную запись одним файлом. Лиги, двойные точки и акценты не предусмотрены.

## Упрощение записи

После генерации приложение сокращает количество знаков в пределах такта:

- соседние паузы объединяются, например две восьмые — в четвертную;
- нота может поглотить паузу после неё, например шестнадцатая нота и шестнадцатая пауза — восьмая нота;
- два удара не объединяются; нота не поглощает паузу перед собой;
- для объединения доступны половинные, четвертные, восьмые и шестнадцатые независимо от галочек генерации; восьмые с точкой доступны только при включённой галочке «С точкой»;
- группы триолей, квинтолей и секстолей не изменяются, их границы и тактовые черты не пересекаются;
- при одинаковом количестве знаков предпочтение отдаётся объединению пауз без изменения предшествующей ноты.

Это правило для коротких ударов на барабанах: оно сохраняет каждый удар и его время, но может продлить обозначенную ноту на время последующей тишины. Если сумма не записывается доступными длительностями без изменения ударов, часть пауз остаётся. После упрощения могут появиться длительности, не выбранные для генерации.

## Воспроизведение

Нажмите «Слушать». Темп — от 40 до 240 четвертей в минуту; метроном можно отключить перед запуском. Громкость регулируется во время игры. «Стоп» прерывает звук, следующий запуск начинается с первого такта. Текущие нота или пауза и такт подсвечиваются.

Каждая нота звучит как один короткий барабанный удар; длительность определяет интервал до следующего события. Паузы молчат. Метроном звучит на каждую четверть, первая доля такта выделена более высоким щелчком.

Звук синтезируется локально через Web Audio API, без скачивания сэмплов и библиотек. План звуков строится из того же этюда, что и ноты. Источники запускаются по аудиочасам с небольшим опережением, а не непосредственно из таймера интерфейса. При остановке отменяются и уже запланированные звуки. Смена вкладки, печать и генерация нового этюда останавливают воспроизведение.

## Проверка

`node tests/generator.test.cjs` проверяет все 1023 непустые комбинации галочек с включёнными и выключенными точками, точную длину тактов, обычные длительности и восьмые с точкой, группы триолей, квинтолей и секстолей, ошибки ввода, раскладку по строкам и неизменность звукового ритма после упрощения.

`node tests/playback.test.cjs` проверяет время ударов и пауз, триоли, квинтоли, секстоли, метроном, звуковые буферы, отмену звуков, завершение и прерывание воспроизведения. Запуск, подсветка, остановка и завершение дополнительно проверены в браузере.

`node tests/simplification.test.cjs` проверяет объединение без ограничений галочек генерации, появление половинных и четвертных только при упрощении, сохранение отдельных ударов, включение и отключение точек только у восьмых.

`node tests/rest-chance.test.cjs` проверяет границы 0–99%, влияние общего ползунка на обычные длительности и группы, отдельные наборы нот и пауз, заполнение тактов и сохранение ударов после упрощения.

`node tests/pdf.test.cjs` проверяет страницы A4, размещение всех тактов без потерь и обрезки, бинарные потоки и смещения объектов PDF. Скачанные файлы на 8 и 64 такта дополнительно проверены в PDF-ридере и визуально.

## Публикация

GitHub Pages публикует корень ветки `main`. Сборка и сторонние зависимости не требуются. После отправки изменений в `main` GitHub автоматически обновляет сайт.

Для работы без интернета сохраните `index.html` и откройте его в браузере. Установка в качестве PWA и офлайн-кэш сайта не включены.
