# Ритмика — генератор этюдов

Приложение: https://creagent.github.io/drum-etude-generator/

Откройте `index.html` в браузере. Один самостоятельный файл: HTML, CSS, JavaScript и SVG, без внешних библиотек, шрифтов и платных сервисов.

## Использование

Задайте количество тактов (1–64). Отдельными галочками выберите ноты и паузы: половинные, четвертные, восьмые, восьмые триоли и шестнадцатые. Нажмите «Сгенерировать этюд».

- Размер всегда 4/4; каждый такт содержит ровно четыре четверти.
- Галочки разрешают обычную длительность и её вариант с одной точкой (×1,5). Отдельных галочек для точек нет. Для триолей сохраняются группы из трёх равных позиций. Генератор использует только выбранные семейства нот и пауз; не все варианты обязательно встречаются в одном этюде.
- Триоли появляются полными группами по три на одну четвертную долю; если выбраны триольные ноты и паузы, они могут смешиваться внутри группы.
- Если для длительности отмечены и ноты, и паузы, вероятность паузы до упрощения — 30%. Можно выбрать только ноты или только паузы.
- Длительности считаются целочисленно (24 единицы на четверть, 96 на такт, 9 на шестнадцатую с точкой), без ошибок округления. Каждый шаг проверяется на возможность заполнить остаток такта.
- Ноты рисуются без стана и счёта долей. Половинные ноты имеют пустую головку; короткие ноты внутри доли соединяются рёбрами, у отдельных шестнадцатых в смешанной группе есть дополнительные короткие рёбра.
- Такты идут в общей строке с тактовыми чертами: четыре, если хватает места, иначе два. Неполная последняя строка допустима. На маленьком экране вся строка масштабируется по ширине, без горизонтальной прокрутки.
- Печать / PDF и экспорт SVG сохраняют общие строки тактов. Лиги, двойные точки и акценты не предусмотрены.

## Упрощение записи

После генерации приложение сокращает количество знаков в пределах такта:

- соседние паузы объединяются, например две восьмые — в четвертную;
- нота может поглотить паузу после неё, например четверть и восьмая пауза — четверть с точкой;
- два удара не объединяются; нота не поглощает паузу перед собой;
- итоговые длительности остаются в выбранных семействах, группы триолей не изменяются и тактовые черты не пересекаются;
- при одинаковом количестве знаков предпочтение отдаётся объединению пауз без изменения предшествующей ноты.

Это правило для коротких ударов на барабанах: оно сохраняет каждый удар и его время, но может продлить обозначенную ноту на время последующей тишины. Если сумма не записывается выбранными длительностями, часть пауз остаётся. После упрощения такт может содержать меньше видов длительностей.

## Воспроизведение

Нажмите «Слушать». Темп — от 40 до 240 четвертей в минуту; метроном можно отключить перед запуском. Громкость регулируется во время игры. «Стоп» прерывает звук, следующий запуск начинается с первого такта. Текущие нота или пауза и такт подсвечиваются.

Каждая нота звучит как один короткий барабанный удар; длительность определяет интервал до следующего события. Паузы молчат. Метроном звучит на каждую четверть, первая доля такта выделена более высоким щелчком.

Звук синтезируется локально через Web Audio API, без скачивания сэмплов и библиотек. План звуков строится из того же этюда, что и ноты. Источники запускаются по аудиочасам с небольшим опережением, а не непосредственно из таймера интерфейса. При остановке отменяются и уже запланированные звуки. Смена вкладки, печать и генерация нового этюда останавливают воспроизведение.

## Проверка

`node tests/generator.test.cjs` проверяет все 1023 непустых комбинации галочек, точную длину тактов, обычные и пунктирные длительности, группы триолей, ошибки ввода, раскладку по строкам и неизменность звукового ритма после упрощения.

`node tests/playback.test.cjs` проверяет время ударов и пауз, триоли, метроном, звуковые буферы, отмену звуков, завершение и прерывание воспроизведения. Запуск, подсветка, остановка и завершение дополнительно проверены в браузере.

`node tests/simplification.test.cjs` проверяет пример пользователя, объединение пауз, удлинение нот, сохранение отдельных ударов и выбранных длительностей, генерацию и отрисовку точек.

## Публикация

GitHub Pages публикует корень ветки `main`. Сборка и сторонние зависимости не требуются. После отправки изменений в `main` GitHub автоматически обновляет сайт.

Для работы без интернета сохраните `index.html` и откройте его в браузере. Установка в качестве PWA и офлайн-кэш сайта не включены.
